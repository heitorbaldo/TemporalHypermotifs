# Temporal Hypergraph Motifs (THMs)

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)]()

------
TemporalHypermotifs is a Python package for detecting, classifying, and quantifying temporal hypergraph motifs (THMs). It implements several measures to compute motif-level, single-layer hypergraph-level, and multilayer hypergraph-level features. This package is based on HyperNetX.
